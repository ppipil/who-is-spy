# M4 Quality Gate evidence files

- `summary.md`: human-readable summary of M4 scope, commands, metrics, and limitations.
- `fake-quality-gate-report.json`: sanitized machine-readable FakeModel regression report generated by `runEvaluation()`.
- `real-quality-gate-smoke-report.json`: sanitized machine-readable DeepSeek smoke report generated by `runEvaluation()`.

Do not add unredacted model inputs, provider payloads, API keys, or complete secret-word logs to this directory.
